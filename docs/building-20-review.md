# 20号館の図面登録と確認項目

## 登録範囲

20号館の掲示案内図から、1〜4Fの室区画と設備の概略配置を転記しています。座標・形状・階高は表示用で、実測値ではありません。

| 階 | 室区画数 | 設備 |
| --- | ---: | --- |
| 1F | 20 | 男女WC、多目的WC、階段3か所、EV |
| 2F | 19 | 男女WC、階段3か所、EV |
| 3F | 41 | 男女WC、階段3か所、EV |
| 4F | 28 | 男女WC、階段3か所、EV、種別未確認の無記名区画 |

合計108室区画のうち、107区画には判読した室番号を付けています。3Fの準備室1区画は室番号の確認待ちです。設備室や準備室も室区画数に含まれます。

地図・3D・検索・場所一覧・端点指定に対応しています。扉位置、直接廊下へ出られる室、室同士の出入口、階段の上下接続、EVの停止階、建物の出入口が未確認のため、20号館の経路は未登録です。模式図の位置だけから経路を作成しません。

出典は `1000006945.jpg`（1・2F）と `1000006946.jpg`（3・4F）の掲示案内図です。図面の改訂日は不明です。写真そのものはリポジトリに収録していません。

## 接続と形状の確認

- 室の上下分割は、その両方が廊下に直接面していることを意味しません。室を通り抜ける接続は、扉と利用条件を確認してから登録します。
- 階段は掲示図の左端・中央・右端という位置で識別しています。公式の階段番号や地理的な東西を示す名称ではありません。
- WCは記号から種別を登録しています。多目的WCの表示から、車椅子で利用できる経路があるとは判定しません。
- 4Fの中央廊下の枝分かれ、無記名枠、準備室周囲の通路幅、1F東端の凹凸と出入口は、図面または現地で照合してください。
- 建物の3D配置座標は単棟表示のための仮配置です。キャンパス図と室内図の縮尺・向きは未校正で、屋外接続や実距離の計算には使用しません。

修正は `src/data/buildings/20/floors/` の該当階JSONに反映し、`npm run validate:data`、`npm test`、`npm run build` を実行します。
