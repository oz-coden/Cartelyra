## 接続と形状の確認

- 室の上下分割は、その両方が廊下に直接面していることを意味しません。奥の部屋は上表の明示的な終点まで案内し、室内の通り抜け接続は登録しません。
- 階段は掲示図の左端・中央・右端という位置で識別しています。公式の階段番号や地理的な東西を示す名称ではありません。
- WCは記号から種別を登録しています。多目的WCの表示から、車椅子で利用できる経路があるとは判定しません。
- 4Fは20-425の両脇と南側、20-416・20-415の間、20-414と20-401の間に廊下の枝を登録しています。1Fの20-114、4Fの20-424・20-425・20-422・20-416・20-415・20-414・20-401のように複数の通路に面する部屋は、主廊下側を代表点にしています。実際の案内と異なる場合は該当室の代表点だけ修正します。
- 屋外区画の境界形状、準備室周囲の通路幅、1F東端の凹凸と出入口は、図面または現地で照合してください。
- 建物の3D配置座標は単棟表示のための仮配置です。キャンパス図は空中写真を参考に北を上に配置していますが、室内図の縮尺・向きは未校正で、屋外の配置座標とは出入口の対応関係で接続し、3D座標を屋外経路や実距離の計算には使用しません。

修正は `src/data/buildings/20/floors/` の該当階JSONに反映し、`npm run validate:data`、`npm test`、`npm run build` を実行します。
