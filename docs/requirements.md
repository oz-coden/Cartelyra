# Uniview 要件と操作仕様

## 目的

神奈川大学 横浜キャンパス内で、建物・部屋・トイレなどの設備・門を探し、登録された接続に沿った経路を確認できる非公式の案内サイトを提供する。

公開物はHTML・CSS・JavaScript・JSONからなる静的サイトとする。地図の表示、検索、場所の選択、経路計算はブラウザー内で完結し、専用サーバー・データベース・ログインを必須にしない。

5号館は外階段に面する2F出入口から館内経路へ接続する。建物の入口を一律に1Fとみなさず、出入口ノードの階を使用する。外階段は館内の階間接続に置き換えない。屋外側は7号館に面する側の3号館寄りから外階段で接続し、階段回避では使用しない。EVは未登録とする。

建物内の場所は棟ID・階を持ち、門はキャンパス上の場所として扱う。門・屋外ノードに架空の棟ID・階番号を割り当てない。キャンパス図は空中写真を参考に北を上にして配置し、出典と概略位置であることを表示する。室内図の模式座標とは混同しない。

場所の選択と、経路の登録状態は別に扱う。入口・屋外経路が未登録でも場所は出発地・目的地として記憶できる。経路がない場合は対象と不足する接続を明示し、近隣の別地点へ自動で置き換えたり、直線で仮の経路を表示したりしない。奥の部屋に限り、同じ階の通路に面した部屋を `approachRoomId` で明示し、その部屋の通路側まで案内できる。指定された部屋の名前を保持し、案内終点の違いを詳細・概要・道順に表示する。

19号館はB1〜3Fを表示する。公開の食堂・ホール・ラウンジは `passThrough: true` を明示した区画だけ内部の参考経路を許可し、厨房・事務室・WC・用途未確認区画には拡張しない。1Fの19-104・19-107は左側通路へ仮接続し、右側通路とは同階でつながない。購買部側出入口は19-101の向かいの下側外周に登録し、左側通路の出入口は現地確認待ちとする。EVはB1〜2F・2F〜3Fを仮接続し、メンテナンスルーム内の可能性がある1F乗り場には共用通路への接続を設けない。屋外経路との対応は未登録。

17号館は1〜5Fを表示する。1F内と2〜5F内は独立した経路区画とし、対応が不明な階段・EVを推測で接続しない。2〜5Fの同位置の階段・EVだけを隣接階へ仮接続する。1Fのシャワー室2区画と5Fの17-540は指定した手前の部屋まで暫定案内する。中央の無記名区画は構造未確認の非通行区画とする。1Fの近接する2開口を出入口1にまとめ、出入口1・2を19号館側の地上通路へ参考接続する。3F出入口の外部接続は保留し、他棟との直接の連絡接続は補完しない。

建物・階・設備・門はJSONで管理する。出典と確認状態を記録し、棟を増やすたびに画面の分岐を追加する設計にしない。

## 状態の分離

| 状態 | 役割 | 他の状態への影響 |
| --- | --- | --- |
| 表示モード | キャンパス・平面図・3D | 出発地・目的地を保持する |
| 表示する棟・階 | 図面と階内の場所一覧を指定 | 出発地・目的地を変更しない |
| 選択した場所 | 強調表示と共通の詳細・アクションを表示 | 同じ棟・表示中の連絡棟群ではカメラを維持。別棟へ切り替える場合はその棟を表示範囲に収める |
| 出発地・目的地 | 検索または選択した場所から明示的に指定 | 経路計算だけで表示階・選択・カメラを変更しない |
| 地図で指定中の対象 | 出発地または目的地の一方 | 設定完了・キャンセル・Escapeで解除する |
| 3Dの全階表示・展開率 | 可視階と階間隔を指定 | 部屋・設備の選択や経路計算で変更しない |
| カメラ | 位置・方向・拡大率 | ドラッグ等の手動操作、視点リセット、3Dへの切り替え、建物選択、明示的な道順カード操作で変更する |

## 連絡棟

屋内・屋根付き通路でつながる棟は、棟ID・階名を保持したまま平面図・3Dでまとめて表示できるようにする。一体表示が既定で、単棟表示へ切り替えられる。階番号が異なっても対応する表示レベルを明示する。3Dの階展開は共通レベル順にそろえ、表示範囲内の棟を選んでもカメラを維持する。表示グループの所属から接続を推定しない。7〜10号館は準備中の棟群として保持し、館内図・接続階・接続形状の登録前に仮の経路を作らない。

## 共通の場所選択

1. 平面図・3D・検索・場所一覧・門一覧から同じ場所IDを選択する。
2. 選択した場所の名前と登録状態を、その場所を指す地図上の吹き出しに表示する。「ここから出発」「ここへ行く」を吹き出し内に配置する。
   - 吹き出しは地図に重ね、表示・非表示によってページのレイアウトやスクロール位置を変更しない。
   - 平面図・キャンパス図のパン／ズーム、3Dのカメラ操作・階の展開、画面サイズの変更に追従する。
   - 地図の端では吹き出しを表示範囲内に収める。選択位置が画面外・カメラ背面・非表示の棟や階にある間は吹き出しを隠し、戻ったら再表示する。
3. 「ここから出発」「ここへ行く」で端点を指定する。地図での指定中なら、場所を選んだ時点で指定を完了する。
4. 平面図の選択・キーボードフォーカスの強調は実際の多角形に沿い、部屋・経路より前面の専用レイヤーで表示する。強調はクリック判定を遮らない。選択の強調は部屋だけに限定しない。3Dでは部屋・WC・EV・階段・AEDを同じ仕組みで発光させ、別の場所を選ぶと前の強調を解除する。
5. 選択を解除したら、詳細とすべての強調を解除する。表示モードの切り替えでは、残っている選択を新しい表示へ反映する。

3Dキャンバスを使えない操作方法にも対応するため、検索と階内の場所一覧からも部屋・設備を選べるようにする。門の選択ではキャンパス図を表示する。

## 3Dの表示・入力

- 初期表示は選択中の建物の全階。全階表示を外すと、選択中の階だけを表示する。
- 展開スライダーを動かすと全階表示へ切り替える。展開率と表示状態を画面に表示し、操作できるのに見た目が変わらない状態を避ける。
- 展開位置は各階の基準高さと積層順から求める。B1→1Fのような階番号の欠番や0階を扱えるようにする。
- スライダーを戻したら元の高さへ戻す。展開中の経路も同じ変換を使う。
- 同じ棟・表示中の連絡棟群の部屋や設備を選択してもカメラ位置・方向・拡大率を変更しない。その範囲外の場所を検索・選択した場合は、新しい表示範囲を収める。全階表示・単一階表示と階の間隔は保持する。必要な場合は「視点リセット」を使う。
- 3Dの緑・赤のピンは経路全体の出発地・目的地だけに表示する。表示区間の途中の端は、別階・屋外への中継地点を紫のひし形で表示する。表示対象が1地点だけの場合も端点の種類に応じたマーカーを表示する。
- 非表示の棟・階は選択対象に含めない。複数階が重なる場合は、手前の可視メッシュを選択する。特定階を選びたい場合は単階表示または場所一覧を利用する。
- 回転・パンなどのドラッグ、右ボタン操作、ピンチ、キャンセルされたタッチは、場所のクリックとして扱わない。ポインターが元の位置へ戻っても、途中でドラッグしていれば選択しない。
- WebGLを開始できない場合は説明を表示し、平面図・検索・経路指定を引き続き利用可能にする。

## 経路案内

原則として通路に面する側へ代表点を置き、廊下から線を伸ばす。正確な扉位置は必須とせず、通路に面する側が一面ならその面を使用する。別の部屋や立入不可区画を横切る場合だけ個別の例外を登録する。

登録されたノードと接続だけを使い、標準・階段回避・屋内優先・階段優先を選べるようにする。道順は棟と階を保持し、明示的なカード操作でその場所を確認できるようにする。

模式図では、既知の階移動数と昇降量未確認の階段・EV接続数の合計を最小化した上で、選択条件による登録済みの参考評価値を比較する。評価値は描画座標から独立させ、図の縮尺・配置変更だけでは経路を変えない。同階の接続がない区画への必要な他階経由は許可する。同棟または同じ連絡棟群の案内では、昇降が同じなら不要な出入りを避ける。門・棟間の移動では登録済みの館内通り抜けを許可する。屋内優先は屋内・屋根付き・屋外または未確認を区別する。屋外階段も概要に表示し、昇降量が不明ならその旨を示す。校正済みの実寸地図では距離を基準にする。

模式座標のままでは実距離・所要時間を表示しない。多目的トイレの種別や階段回避フラグから、車椅子で通行できると判定しない。現地未確認の接続は除外可能にする。

## 検証と段階的な拡張

現段階では、3号館の6フロアで室内閲覧・参考経路と共通操作を検証する。5号館の4フロアでは、2F出入口からの館内経路、階段のみの階間接続、奥の部屋への暫定的な案内範囲を検証する。20号館の4フロアでは室内閲覧・設備選択・出入口からの参考経路・奥の部屋の案内範囲を検証する。3号館と20号館は西門経由の屋外参考経路で接続する。今後は現地照合、屋外経路の拡充と他棟の図面追加を進める。現在地の自動測位、開放状況のリアルタイム更新、避難誘導は別途要件化する。

回帰確認では、機能ごとの単体確認に加え、3Dで部屋を選び出発地にする→WCを選び目的地にする→経路を表示する→展開率を変更する一連の操作を確認する。発光、端点、表示階、展開率、カメラへの影響を同時に検査する。実ブラウザー・WebGL・モバイルでの描画と操作の確認は、DOMやCPU上の3Dテストとは分けて記録する。

1号館の9フロアでは、階段・EVによる参考移動、1-106の入口空間、3F・4Fの中央室と他階の吹き抜けの違いを確認する。5F左側の1-514と1-516-1を隣接させ、1-512・1-515を1-514の角に配置する。1-516-1を含む奥の4区画は指定した手前の部屋まで、1-B108は1-B107・1-B109間の通路から暫定案内する。1-308-1・1-308-2は別々の案内先とし、分割運用と進入関係を現地調査で見直す。確認事項を[図面登録記録](building-1-review.md)に保持する。1-106側に並ぶドア2か所は1つの出入口にまとめ、窓口ロビー側と合わせて1Fの2出入口を屋外参考経路へ接続する。1-106側は2号館側、窓口ロビー側は東門側とし、開閉方式は未確認とする。

6号館は1〜4F・68区画を登録し、66区画へ直接、6-117は6-118、6-306は6-306-1の通路側まで参考案内する。6-204は女子トイレと重ならない面から接続する。1F・2Fの出入口は館内のみ接続する。3Fの左側廊下と6-308側は同階接続を補わず、灰色区画を通り抜けない。4Fの光庭2か所は歩行不可。現地確認待ちの制限は[図面登録記録](building-6-review.md)と選択説明に保持する。
