## 周辺道路の背景表示

2026年10月22日 UTCに同範囲の地理院タイルの写真を再参照し、西側外周、南側、東門付近、6・5号館北側と中央部の主要な道路を少数の頂点で簡略化します。中央の道路は6・19号館間から12・7号館間、10・12号館間、15・9号館間を経て南側の道路へ続きます。接続関係は通路の模式的な補足図とも照合します。薄い線は方向や周辺の形を把握するための目印で、路面境界・幅員・歩道や横断位置を確定したものではありません。写真原本や道路名を推測して収録しません。

道路と建物の重なりを避け、表示する線幅の外側に余白を確保します。写真の屋根位置をそのまま壁とみなさず、北側・南東側の道路の折れ線を整理し、29号館の小さな模式外形は道路との隙間を見分けられる位置へ概略調整します。この余白と位置調整は図の可読性のためであり、実際の幅員や測量精度を示しません。細長い斜めの建物ではラベルを長辺に沿わせ、縦長で幅の狭い建物はラベルを折り返し、文字全体を外形の内側に収めます。全体表示には建物・門・道路の範囲を含めます。

表示用道路は `overview.contextRoads`、案内用の接続は `campus.outdoor` に分けます。道路沿いを歩く経路も明示的に登録できますが、背景線の交差を理由に新しい経路を生成しません。新たな道路区間を案内へ追加する場合は、歩行可能な側、横断位置、段差と利用条件を確認し、地上・橋上の層と接続先を記録します。

## 歩行時間による距離の概算

平坦な既知距離の区間を普段の速さで数回歩き、距離の合計を歩行時間の合計で割って平均速度を求めます。例えば、巻き尺などで20mの区間を確保し、同じ条件で往復して計測します。スタート前や停止後の時間は含めません。

```text
平均速度 [m/s] = 基準区間の距離合計 [m] / 歩行時間合計 [s]
推定距離 [m] = 平均速度 [m/s] * 対象区間の歩行時間 [s]
```

曲がり角・入口・階段前など、あとから再識別できる地点で区間を分けます。混雑、立ち止まり、扉の開閉時間は歩行時間と分けて記録します。階段や大きな坂には平地の速度をそのまま使わず、段数・階数と所要時間を別に記録します。幅員も歩行時間から推定せず、必要な場所を別に測ります。

| 記録する項目 | 内容 |
| --- | --- |
| 始点・終点 | 棟・階・角・柱など、再確認できる目印やノードID |
| 計測日・方法 | 巻き尺、レーザー、歩行時間による推定など |
| 生の観測値 | 基準距離、各試行の秒数、対象区間の秒数、停止時間 |
| 算出値 | 平均速度、推定距離。実測と推定を区別 |
| 条件と補正 | 平地・坂・階段、混雑、補正前後の値と補正理由 |

観測値は描画用座標と分けて保存し、見た目を整える補正で上書きしません。参考程度の推定は丸めて扱い、過剰な精度を表示しません。現在の経路JSONへメートル値をそのまま `distance` として混在させず、室内・屋外の単位と境界の移動コストを統一してから距離・時間表示へ反映します。現段階の距離・徒歩時間は「未測定」です。
